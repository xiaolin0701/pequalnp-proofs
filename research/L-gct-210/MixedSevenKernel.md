# 活动格上的行列联合秩七限制四阶核的支撑

设 L 为五阶复矩阵的十维方向空间，per(J+T)=120 对所有 T∈L 成立，其中 J 全一。取一个在 L 上可以变化的格子 (i,p)，假设第 i 行、第 p 列投影的秩均为四，且这两个投影的联合秩为七。把这行与这列同时清零、再删除，所得四阶方向空间记为 N。

**结论。** N 维数为三，且每个 X∈N 的全部十六个三阶 permanent 都是零。其支撑或缺整行、或缺整列、或全部包含在同一行与同一列的并中。最后一种情形里，N 本身含非零纯行或纯列方向。

**三阶式。** 按行列重排把 (i,p) 移至右下角。平移后两个投影的像各是一个避开原点的四维仿射超平面。对它们的右下角取公共值等同于在直积上加一条独立方程，因为交点的数值可变，所以此纤维积维数七。题设的联合像也有维数七，故是整个纤维积。在右下角为零的切片上，余下的横行向量 a 和直列向量 b 各在四维坐标里独立遍历不经过零的仿射三维超平面；它们各自的线性包都是整个四维空间。

对 X∈N 和任一具有上述边界的 J+T，取 per(J+T+tX) 的三次系数。选取三个内部 tX 格，留下的两行、两列中，右下角为零，剩余配对必须使用横、直各一格。系数因此是三阶余 permanent 矩阵 G(X) 与 b⊗a 的配对。因 a,b 可独立选取，且各自张满四维，得 G(X)=0。由秩加核维数公式，dim N=10−7=3。

**四阶支撑的有限分类。** 以下只需考虑 N 的四行四列均活跃。取参数泛点，可得到一个四阶矩阵，其非零位置恰是 N 的活动位置。对于全部三阶 permanent 均为零、且每行每列非零的四阶复矩阵，按行列置换和转置只有三种支撑。

* 两个互补的满 2×2 块。
* 一行与一列的并，交点活跃。
* 一行与一列的并，交点为零。

小规模精确分类可用 [check_four_core_masks.py](check_four_core_masks.py) 复核。程序枚举所有无空行列的 4×4 零一支撑对称类。对每个支撑，以非零行列缩放把二分支撑图一棵生成森林上的格都归一化为一，余格取非零不定元。逐一写下十六个三阶 permanent 并加入“变量乘积可逆”的方程。若存在单项式方程则立即矛盾；其余情形在有理数上计算 Gröbner 基是否含一。由零点定理，判定在复数上精确。三个留下的行掩码为 (3,3,12,12)、(1,1,1,15)、(1,1,1,14)。相关的一般极小素理想分类见 Kirkup 第九节定理 14；这里的四阶支撑清单另由有理数上的枚举直接核验。[George A. Kirkup, Minimal Primes Over Permanental Ideals](https://arxiv.org/pdf/math/0510025#page=16)

**排除满块。** 两个满 2×2 块记作 A,B。用另一块的一个活跃格与某块完整行列组成三阶式，得 per₂(A)=per₂(B)=0 在 N 上恒成立。令 s,t 是两块各自的元素和。一阶条件给 s+t=0；二阶条件为两个内部二阶 permanent 加上各跨块的匹配，故 st=0。于是两块各自的元素和也恒为零。二阶 permanent ad+bc 是非退化四元二次型，而总和超平面 a+b+c+d=0 是其中一个非迷向向量 (1,1,1,1) 的正交补。该超平面是非退化三维空间，其全迷向线性空间维数至多一。每一块的投影故至多一维，dim N≤2，矛盾。

**十字支撑中的纯方向。** 把十字支撑的特殊行和特殊列分别称为横、直，两者交点记为 z。令 s,t 分别是横、直两臂上不含交点的坐标和。一、二次水平条件给 s+t+z=0 及 st=0，故在整环上 s 或 t 恒零。若 s=0，横臂只在三个位置变化且总和零，投影秩至多二。N 有三维，必有非零方向的横臂为零，此方向仅支撑在直列。t=0 时同理可得纯行方向。交点原已为零时，证明同样适用。

## 联合秩六时的余式直线

保留五阶恒值、指定格活动及各轴投影秩四的条件，改设联合秩为六。此时 N 维四。存在固定秩二矩阵 G₀，使 N 中所有 G(X) 都在直线 ℂG₀ 中；允许它们全为零。

事实上，在右下角设零后，a、b 的仿射像仍分别是三维超平面，记其归一化方程为 A(a)=B(b)=1。联合切片现在是五维，恰为其直积中的一道仿射方程 c(a)=d(b)。因为两个投影都满射，c、d 各自都非常数。可分别将它们延拓为原四维向量空间上的线性形式，满足 A、c 独立且 B、d 独立。上述三次系数保证 aᵀG(X)b 在此切片为零。作为两个三维仿射变量 a、b 上的多项式，它被 c(a)−d(b) 整除，且对各组变量的次数均至多一。该混合因子对各组都恰一次，所以商为常数 λ(X)。在 A(a)=B(b)=1 上即得 aᵀG(X)b=λ(X)(c(a)−d(b))。分别齐次化两组变量推广到整个四维直积，右端为 λ(X)(c(a)B(b)−A(a)d(b))，所对应的固定 G₀ 恰为秩二。因此证明直线结论。

当这族余式并非恒零时，还能逐行逐列获得线性约束。因为 X 只支撑在内部四阶块，其四阶 permanent 是五阶水平条件中最高次系数，故 per₄(X)=0。按任一行、列展开，由 G(X)=λ(X)G₀ 和参数多项式环无零因子，得到对每行 i、每列 j 分别有 ∑ₖXᵢₖ(G₀)ᵢₖ=0，∑ₖXₖⱼ(G₀)ₖⱼ=0。

当 N 的四行四列均活跃且 G 并非恒零时，公共三次式 λ 是三个矩阵坐标线性型的乘积（计重数，允许乘非零常数）。证明如下。对任一点 λ(X)=0，全部三阶余式都消失，故该点要么少一个行或列，要么落在有限个十字支撑或双 2×2 块支撑中的一个。这些都是坐标子空间。N 整体不在任何一个之中：四轴全活跃排除缺行列，十字支撑会迫 G 恒零。若 N 在两个互补满块的坐标空间内，per₄(X)=per₂(A)per₂(B)=0 的恒等式说明至少一块的投影在二阶二次型上全迷向，维数至多二。将此块清零，另一单块上的剩余空间至少二维，但其全部元素之和与二阶 permanent 必同时为零，按前面的非退化三维二次型论证至多一维，矛盾。

因此每个可能支撑的坐标子空间都漏掉 N 的至少一个活动格。λ 的零集包含在有限多个真坐标超平面的并中。代数上，这些非零坐标形式的乘积在 λ 的零集上消失；零点定理与唯一分解说明 λ 的每个不可约因子一定就是其中某个一次式的非零倍数。λ 齐次三次，即得乘积分解。把每个这样的格子清零，所得三维截面内 G 全零。应用上述三阶余式支撑分类，此截面或缺整行或整列，或落在一个十字支撑内。

**秩六切片的低秩轴。** 四维 N 的八个行、列投影中，至少一个的秩至多一。若 N 已缺整轴，此事显然；若 G 恒零而八轴全活动，支撑分类只剩十字，非中心行就有秩一。以下设 G 非恒零，并反设八轴投影秩均至少二。

λ 的每个一次因子 l 定义 N 的一个三维超平面 D_l。限制到超平面只能使各轴秩减少至多一，故 D_l 四行四列皆活跃，又有 G=0；上面的分类迫它位于同一行与同一列构成的十字中，六个臂格均活跃。

先证此因子必为单根。取 D_l 内一个六个臂格全非零的 X，将中心行、列排在首行、首列。用 x_a 和 y_i 表示横、直两臂的不含交点的非零元素（i,a 取三个非中心索引）。若 l² 整除 λ，则对每个方向 T∈N，全部三阶余式在 X 沿 T 的一阶导数都为零。固定另两行 i,j 和另两列 a,b，展开同时包含中心行与中心列的三阶式的一阶项。只有在外部 3×3 块取一个 T 元素才能匹配，上下两臂各贡献一个非零项。以 t_{ia}=T_{ia}/(y_i x_a) 记归一化的九格，除以 y_i y_j x_a x_b 后得

    t_{ia}+t_{ib}+t_{ja}+t_{jb}=0。

这对任意两行与两列都成立。把三个坐标映到其三个两两和的 3×3 线性变换可逆（行列式绝对值二）；先对行、再对列用该变换得全部 t_{ia}=0。于是 N 的每个方向都在同一十字中，和 G 非恒零矛盾，证毕单根性。

所以 λ 有三个彼此不同的一次因子，对应三个十字。两个十字若同一中心，其两个不同超平面会张成 N，使 G 恒零。若两个中心既不同行又不同列，两十字的交只有两个格，而两个超平面在 N 中交于二维；支撑在两个格且一阶元素和恒零的空间最多一维，同样矛盾。故三个不同的中心必共享同一行且分处三列，或共享同一列且分处三行。

现在对每个 l 选取 D_l 的一个点，使它不落在其余两个超平面上。沿一个 l(T)≠0 的方向，λ 的一阶导数非零。在该十字上，删除其中心行或中心列所得的每个三阶式的一阶导数却都是零：任一三阶匹配至少需要两个十字外的格。因此固定的 G₀ 在该中心行、中心列均恒零。三个中心给出三个不同的零行或零列，迫 rank G₀≤1，和前面的精确秩二矛盾。由此必有投影秩至多一的轴。

## 交点固定时也成立

如果选中的格子在方向空间 L 中恒零，则平移后该格固定为一。各轴仍假设秩四。对 X∈N，沿 tX 的三次系数这时多一类配对：若最后两行列选用交点，则还要选取内部矩阵 M 的一个格。整个系数为 G(X) 与 M+baᵀ 的配对，其中 a,b 为平移后的横、直边界。再就 Y∈L 取齐次二次项，M 是仿射函数而消失。得到在边界方向的联合空间 S 上恒有 a′ᵀG(X)b′=0。由于交点方向为零，a′、b′ 的各自像都是整个四维空间。

设 r 是联合秩，m=8−r。S 由 m 条线性方程 C(a′)=D(b′) 定义，两侧线性映射的秩均为 m（否则某个轴投影不满）。对 a′ 加任意 C 核方向并保持 b′，取差可知左侧双线性型在 ker C 上消失；对另一侧同理。因此存在 m 阶矩阵 H，使 a′ᵀG(X)b′=C(a′)ᵀ H D(b′)。在 S 上取任意共同的 m 个参数 z，得 zᵀHz=0，故 H 反对称。当 r=7 或 8，有 m≤1，G(X)=0；当 r=6，有 m=2，反对称矩阵空间一维，非零生成元秩二。因而前面的秩七支撑结论和秩六的低秩轴结论，对固定交点同样成立。

## 秩一轴的三维截面不能是满十二格、每行秩三的循环型

设混合秩六的 N 在最后一行投影秩一，把此行清零得到三维 D。若 D 的其余 3×4 部分十二格全活跃且每个行像秩三，则矛盾。转置可交换两个轴。

若 G≡0，N 已包含 D 的十二格且另有第四行活动，四列全活动，违反双满块或十字的支撑上界。故 G=λG₀ 非恒零。写第四行为 tw，t 是 N 上的非零一次式。因 G₀ 的秩为二，其上三行不可能全零。那些上三行的余式都包含第四行的一个元素，故 t 整除 λ。于是 D 上全部三阶余式为零。D 补一恒零列后满足三行五列矩形水平条件：在全一基点处，补零方向对应的各阶匹配系数仅相差非零常数。因此可用[满十二格分类](./FullFourColumnClassification.md)。重排后以 a,b,c,t 为参数，N 的上三行四列为

    X₁=a u+t m₁，X₂=−a u+t m₂，X₃=b v+t m₃，X₄=c v+t m₄，

其中 u=(1,ω,ω²)，v=(1,ω²,ω)，ω²+ω+1=0。记 e=(1,1,1)。对任意两个三向量 x,y，R(x)y 为其三个二阶永久式向量，坐标按被删行排列。有 R(u)u=2v，R(v)v=2u，R(u)v=−e，且 R(v) 可逆。

取 G 上三行关于 t 的一次系数。按被删列 1,2,3,4，其四个列向量依次为

    2bc w₂u+(ac w₃+ab w₄)e，
    2bc w₁u−(ac w₃+ab w₄)e，
    ac(w₁−w₂)e−2a²w₄v，
    ab(w₁−w₂)e−2a²w₃v。

由于这些 3×4 矩阵在同一条固定直线上，每个参数单项式的矩阵系数也都在该线上。若 (w₁,w₂) 和 (w₃,w₄) 都非零，则 bc 项与 a² 项非零且支撑不交，矛盾。若只有后一对非零，则 a² 项与 ab 或 ac 的非零项亦不可能成比例。于是前一对非零、后一对为零，再由 bc 项与 ab、ac 项比较，得 w₁=w₂≠0。缩放第四行参数后可取 w=(1,1,0,0)。G₀ 在上三行的列组因而正比于 (u,u,0,0)。

用这个固定形状回到完整的 G。其上三行第三列恒零，按底行展开即得 t R(X₁+X₂)X₄=0。取 t²c 项，得 R(v)(m₁+m₂)=0，故 m₁+m₂=0。上三行第一列是 t R(X₃)X₄，并总在 ℂu 内，比较 t²b 与 t²c 项得 R(v)m₃、R(v)m₄ 均在 ℂu 中。由于 R(v) 可逆且 R(v)v=2u，必有 m₃,m₄∈ℂv。四个上部列的元素和从而始终为零：前两列互相抵消，后两列均在零和直线 ℂv 上。第四行的元素和却为 2t，违反五阶全一水平的一阶方程，证毕。
