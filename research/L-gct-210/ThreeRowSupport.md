# 三行、五列且全部三阶 permanent 为零时的支撑分类

以下在复数域上工作。设 \(D\) 为三行五列矩阵的线性空间。称格子活动，是指该位置作为 \(D\) 上的线性函数非零。假设对每个 \(X\in D\)，从 \(X\) 任取三列组成的方阵，其 permanent 均为零。本结论适用于五阶问题中已经推出这条三阶余式条件的分支。

**定理。** 若三行和五列均有活动格，可重排行列，使第二、三行具有相同的活动列集合 \(I\)，其中 \(1\le |I|\le2\)。将这两行限制在 \(I\) 上，它们的全部二阶 permanent 恒为零。第一行须覆盖 \(I\) 以外的列。因此全空间最多有九个活动格。反过来，这种支撑形状连同所述二阶条件足以保证所有三阶 permanent 恒为零。

若 \(\dim D=3\)，投影到第二、三行的像至多二维，故 \(D\) 中至少有一个非零方向只支持在第一行。若再知相应矩形 permanent 在全一基点恒定，这个纯行方向的行和必为零。

## 两行的二阶条件

设两个非零行向量为 \(b,c\)，且 \(b_i c_j+b_j c_i=0\) 对每对不同的列都成立。取 \(b_i\ne0\)。若 \(c_i=0\)，逐个取 \(j\ne i\) 就得到 \(c_j=0\)，矛盾。交换两行可知其支撑相同。对支撑内每个 \(j\ne i\)，比值 \(c_j/b_j\) 等于 \(-c_i/b_i\)。若还有两个这样的列 \(j,k\)，它们之间的二阶式要求两个相等的非零比值互为相反数，矛盾。故共同支撑至多有两列。

当 \(|I|=2\) 时，二行二列上的 permanent 为 \(ad+bc\)。其极化是四维非退化对称型。恒使 \(ad+bc=0\) 的线性空间包含于自身的正交补，故维数至多二。若 \(|I|=1\)，两行的投影本来就只有两个坐标。这证明定理的维数推论。

## 五列分类的证明

在 \(D\) 中取一个在每个活动格均非零的矩阵。这种矩阵存在，因为有限个真超平面之并无法覆盖复向量空间。以下先对这个矩阵讨论支撑。

若某列只有一个非零格，重排使它在第一行。将该列与其他任意两列组合，对唯一的非零格展开三阶 permanent，就得到另外两行在所选两列上的二阶 permanent 为零。涉及该单格列的二阶式也为零。上一节因此给出所需的共同支撑。

若各列至少有两个非零格，则三个行合计至少十格，某行占至少四格。将它排在第一行，记另外两行为 \(b,c\)。以下证明这两行只能共占至多两列，与本段的列支撑假设矛盾。

1. **第一行占五列。** 对每列独立作非零缩放，将第一行化为全一。记 \(d_{ij}=b_i c_j+b_j c_i\)。每个三阶式给出 \(d_{ij}+d_{ik}+d_{jk}=0\)。对全部十个三元组求和，每条边恰出现三次，故全部边权之和为零。固定顶点 \(i\)，再对包含它的六个三元组求和，得到三倍的邻边和加上全部非邻边之和为零。由总边权和为零可知邻边和为零。最后固定边 \(ij\)，对包含它的三个三元组求和，得到 \(3d_{ij}-d_{ij}-d_{ij}=0\)。因此全部 \(d_{ij}\) 为零，两行支撑相同且至多两列。
2. **第一行占四列。** 同理将它化为 \((1,1,1,1,0)\)。第五列有活动，故 \(b_5,c_5\) 至少一个非零。设 \(h_i=c_5b_i+b_5c_i\)（\(i\le4\)），使用第五列的三阶式给出每个 \(i\ne j\) 的 \(h_i+h_j=0\)，从而所有 \(h_i=0\)。若 \(b_5,c_5\) 恰有一个为零，对应的整行都会为零。故二者均非零，前四列满足 \(c_i=-(c_5/b_5)b_i\)。在前四列的任意三列上展开三阶式，除去非零因子，得到对应三个 \(b_i\) 的两两乘积之和为零。令 \(s=\sum_{i\le4}b_i\)。对这四个等式求和，得全体两两乘积的两倍为零。再从全体两两乘积中减去每次删除 \(j\) 的等式，得到 \(b_j(s-b_j)=0\)。所有非零 \(b_j\) 因此都等于 \(s\)。它们之和也是 \(s\)，故至多有一个。加回第五列，第二、三行仍只占相同的至多两列。

由此必有一个单格列，矩阵的支撑已有所述形状。由于最初选取的矩阵同时实现了 \(D\) 的全部活动格，同一支撑限制对整个 \(D\) 成立。固定上述单格列后，相应三阶式在 \(D\) 的多项式环上是该格的非零线性函数乘以另外两行的二阶式。整环无零因子，故二阶式在整个 \(D\) 上恒零。逆向结论由沿第一行展开任一三阶式直接得到。

## 恒值空间中界的可达性

将三行五列方向 \(X\) 补上两条零行，嵌入五阶方向空间。若记三行向量为 \(a,b,c\)，则 \(\operatorname{per}(J+X)\) 的一次项是三行总和乘 \(24\)，二次项是所有不同行对的 \((\sum a)(\sum b)-a\cdot b\) 之和乘 \(6\)，三次项是十个三列 permanent 之和乘 \(2\)。更高次项为零。

**三行五列全部出现，九个活动格。** 以下三维空间以 \(s,p,q\) 为独立参数。

    a = (−2s, −2s, p, q, 2s−p−q)
    b = (  s,   s, 0, 0, 0)
    c = (  s,  −s, 0, 0, 0).

三行之和依次为 \(-2s,2s,0\)，故一次项为零。两末行的二阶 permanent 为零，因此它们对二次项的贡献及全部三阶式均为零。对第一行与后两行合并计算，\(b+c=(2s,0,0,0,0)\)，得到 \((-2s)(2s)-a\cdot(b+c)=0\)。这验证了恒值性，也表明九格界可取到。

**仅四列出现，十二个活动格。** 取三次本原单位根 \(\omega\)，设 \(u=(1,\omega,\omega^2)\)，\(v=(1,\omega^2,\omega)\)，令五个列向量依次为

    s u, −s u, p v, q v, 0.

列和均为零，且 \(u\cdot u=v\cdot v=0\)。从列方向计算二次项，混合的 \(u,v\) 项因前两列取相反数而抵消。任意三个非零列的类型只能是 \(u,u,v\) 或 \(u,v,v\)。按行分别除以 \(u_i\) 后，\(v_i/u_i\) 的三个值是 \(1,\omega,\omega^2\)。它们的一次、二次初等对称式均为零，所以两类三阶式都为零。这也是三维恒值空间，前三行、前四列的十二格全部活动。因 \(u,v\) 的每个分量都非零，只要其中一行消失就有 \(s=p=q=0\)，故没有非零纯行方向。将九格上界或纯行方向的推论应用于更大空间时，都要先核对五列全部出现。
