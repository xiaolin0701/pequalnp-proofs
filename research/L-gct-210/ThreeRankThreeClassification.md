# 三维三行核各行投影秩三时的分类

设 D 是 3×5 复矩阵的三维线性空间。假设三个行投影的秩均为三，D 每个点的全部齐次三阶 permanent 都为零，且在 J+D 上所有三列 permanent 的和恒为 60（J 为 3×5 全一矩阵）。则可以置换行列，将 D 的五列写作

    a u, −a u, b v, c v, 0，
    u=(1,ω,ω²)，v=(1,ω²,ω)，ω²+ω+1=0，

其中 a,b,c 为三个独立参数。

**活动列的数目。** 若五列都活动，三行均非零，[五列支撑定理](./ThreeRowSupport.md) 迫使其中两行各仅用至多两列，和行秩三冲突。若只有三列活动，把方向限制到这三列，三阶方阵 permanent 在全一基点也恒等于六：各阶匹配之和相同，只是补足匹配的常数系数不同。某行若有秩三就能在平移后完全清零，矛盾。更少列不能有行秩三。故恰四列活动。

在泛点处以 D 的有理函数域为系数工作，所有活动格均非零。四个活动列中，每行至少三格活动。若有一列仅一格活跃，含该列及任何另外两列的三阶式迫使余两行全部二阶 permanent 为零。非零的两行满足此条件时，它们仅共占至多两列（见五列支撑定理的两行论证），矛盾。以下四列均至少两格。

**九格或十格。** 九格时每行各缺一格，且三个缺格必须位于不同列。唯一的满列用非零行缩放成 (1,1,1)，余三列为 (0,a,b),(c,0,d),(e,f,0)，字母均非零。设 r=b/a,s=d/c,t=f/e。三阶式给 1+r+s=0，1+r+rt=0，s+rt=0，立即矛盾。

十格时，满行可用列缩放化成 (1,1,1,1)，其它两行的零格位于不同列。写两行为 (0,A,B,C),(D,0,E,F)。三阶式在列 123、124 上分别给 E/D=−1−B/A，F/D=−1−C/A。再用列 134 上的式子 BF+CE+(B+C)D=0，得到 −2BCD/A=0，和各量非零矛盾。此两类的缩放只用于检验齐次三阶式。

**十一格。** 排好列使唯一缺格位于末行首列。按首行归一，前两行为 (1,1,1,1)、(s₁,s₂,s₃,s₄)，第三行是 (0,v₂,v₃,v₄)。对 i,j∈{2,3,4}, i≠j，由含首列的三阶式有

    (s₁+sᵢ)vⱼ+(s₁+sⱼ)vᵢ=0。

故三个比值 (s₁+sᵢ)/vᵢ 两两互为相反数，均为零，得到 s₂=s₃=s₄=−s₁。s₁ 必为常数：若它是最简的非常一次式之比，则其一次分母整除首行所有四格的坐标线性式（因为第二行原坐标也都是一次式），首行秩至多一。

撤销所有列缩放，原三行为 (a,b,c,d)、(sa,−sb,−sc,−sd)、(0,x,y,z)，其中 s 非零常数。余下的三阶式是 cdx+bdy+bcz=0。这是 D 的坐标多项式环中的恒等式。若 b,c,d 两两不成比例，分别模去 b,c,d，即得 x 是 b 的倍数、y 是 c 的倍数、z 是 d 的倍数。于是四列全都秩一，[四个秩一列的分类](./FourCenteredColumns.md) 迫使四个活跃列的所有十二格都活动，矛盾。若 b,c,d 全同线，首行秩至多二。

余下必是恰两者同线。置换后三列后设 c=kb，其中 k≠0。此时 a,b,d 线性独立。三阶式化为 d(kx+y)+kbz=0，故有 z=hd 和 y=−kx−khb，h≠0。写 x=ra+σb+τd，末行秩三迫 r≠0。先令 b=d=0，方向矩阵的三行成为

    (a,0,0,0)，(sa,0,0,0)，(0,ra,−kra,0)。

水平的一、二次条件分别是 1+s+(1−k)r=0 和 (1+s)(1−k)r=0。故两个加数皆零，从而 s=−1、k=1。再对完整矩阵使用一次条件，得到 (4−h)b+(h+2)d=0。b,d 独立，这迫使 h 同时为 4 和 −2，矛盾。

只剩十二格全部活动。[满十二格分类](./FullFourColumnClassification.md) 给出开头的循环空间；该空间确实满足三个假设。特别地，将它补上第四行零后，任何四行五列恒值且五个齐次四阶余式落在同一固定直线的扩张都至多六维，且该界可达。[扩张上界与构造](./RectangularSeedExtensions.md)

进一步，在五阶原问题中只要一个三行截面满足本定理的条件，整个方向空间的维数便至多九。因此十维候选不可能有这样的三行截面，即使最初选取的两外行秩都为四。[循环种子排除五阶十维扩张](./CyclotomicTenObstruction.md)
